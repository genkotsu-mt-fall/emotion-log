# アーキテクチャ文書

このフォルダには、システム全体へ継続的に影響する技術判断と、その判断を理解するための文書を置く。

## ADR

- 保存先: `adr/NNNN-short-title.md`
- 一つのADRには、一つの独立した技術判断を記録する
- 採用済み判断を変更する場合は、新しいADRで旧ADRをSupersedeする
- 局所実装、短命で可逆な選択、未決定の比較だけでは作らない

ユーザーがADR専用のワークフローを選ぶ必要はない。

通常の議論を`docs/skills/000-workflow.md`で進め、議論終了時にChatGPTがADRの必要性を判断する。同じ結論が要件、UX、ロードマップ、OQ、CHANGELOGへ影響する場合は、一つのCopilot向けinstructionでまとめて反映する。
