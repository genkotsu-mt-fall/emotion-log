# ポインター操作仕様案

- 版: 0.1.0
- 状態: Experimental
- 作成日: 2026-07-25

## 1. 目的

時系列表示において、ログ選択、横方向のパン、ページの縦スクロールを誤動作なく区別する。

閾値の数値は確定値ではなく、初期プロトタイプ用の候補とする。

## 2. 状態

```text
idle
  └─ pointerdown → pending

pending
  ├─ pointerupかつ移動量が選択閾値未満 → select
  ├─ 横移動がパン開始条件を満たす → panning
  ├─ pointercancel → idle
  └─ 対象が操作除外要素 → idle

panning
  ├─ pointermove → 表示時間範囲を移動
  ├─ pointerup → idle
  └─ pointercancel → idle
```

MVPでは長押し専用操作と慣性パンを含めない。

## 3. 操作開始対象

### グラフ背景

横方向の移動が条件を満たした場合、パンを開始する。

### データ点

- 移動が閾値未満ならログ選択
- 移動が閾値以上ならパン
- パン終了直後のクリックではログを選択しない

### ボタン・入力要素・詳細領域

グラフのパンを開始しない。各要素の通常操作を優先する。

## 4. 距離判定

開始位置を`(x0, y0)`、現在位置を`(x1, y1)`とする。

```text
dx = x1 - x0
dy = y1 - y0
distance = sqrt(dx² + dy²)
```

初期候補:

- マウスのドラッグ開始閾値: 5 CSS px
- タッチ・ペンのドラッグ開始閾値: 10 CSS px

タッチは指のぶれが大きいため、マウスより広い閾値とする。

## 5. 方向判定

時系列表示は横パンを優先する。

パン開始条件の初期候補:

```text
abs(dx) >= deviceThreshold
かつ
abs(dx) >= abs(dy) × 1.2
```

縦移動が横移動以上の場合は、ブラウザまたは画面の縦スクロールを優先する。

数値は実機検証で調整する。

## 6. Pointer Events

実装技術が対応する場合、マウス・タッチ・ペンをPointer Eventsで統一する。

パン開始後はポインターキャプチャを使用し、ポインターが表示領域外へ出ても操作を継続できるようにする。

次を必ず処理する。

- `pointerdown`
- `pointermove`
- `pointerup`
- `pointercancel`
- ポインターキャプチャの解放

## 7. タッチとページスクロール

グラフ領域で横操作を受け取りつつ、縦方向のページスクロールを妨げないことを要求する。

Web実装の場合の初期候補:

```css
touch-action: pan-y;
```

ブラウザと実機で、次を確認する。

- iPhone Safari
- Android Chrome
- デスクトップChrome系ブラウザ
- キーボードおよびマウス

## 8. クリック抑制

一度でもパン状態へ移行したポインター系列では、終了直後に発生するクリックやタップ選択を無効にする。

これにより、時間軸を動かした直後に意図しないログ詳細が開くことを防ぐ。

## 9. キーボード操作

- データ点を順番にフォーカスできる
- EnterまたはSpaceでログ詳細を開ける
- 時間移動用の明示的なボタンを提供する
- 左右キーなどのショートカットは、他の操作と競合しない範囲で検討する
- フォーカス位置を視覚的に確認できる

## 10. 受け入れ条件案

- データ点を押してほとんど移動せず離すと、そのログを選択する
- 背景を横方向へドラッグすると、表示時間範囲を移動する
- データ点からドラッグを開始しても、閾値を超えればパンになる
- 縦方向のスワイプでは画面をスクロールできる
- パン終了時に意図しないログ選択が発生しない
- 表示領域外でポインターを離しても操作状態が解除される
- `pointercancel`後にパン状態が残らない
- マウス、タッチ、ペン入力で利用できる
- キーボードだけでも時間移動とログ選択ができる

## 11. テスト観点

- 閾値直前と直後
- 斜め方向への操作
- データ点からのパン開始
- 背景からのパン開始
- 高速なフリック
- ポインターが領域外へ出る操作
- 複数指入力
- ブラウザによる`pointercancel`
- 縦スクロールとの競合
- パン中の追加データ取得
