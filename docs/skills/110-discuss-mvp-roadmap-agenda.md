# 110: MVPロードマップセットの一議題を議論する

## 目的

MVPリリースまでの大項目、境界、順序、依存関係について、最小議題一件だけを議論する。

## 必ず参照

- `docs/skills/020-single-agenda-session.md`
- `docs/roadmap/000-mvp-release-plan.md`
- 正本文書、ADR、OQのうち議題に関係するもの

## 議題例

- この成果を独立したロードマップにするか、隣接ロードマップへ含めるか
- 本番環境の準備と本番リリースを同じ大項目にするか
- 認証基盤の成立をどのロードマップの完了条件にするか
- 利用検証の準備をリリース前の必須大項目に含めるか

「MVPまでのロードマップを決める」のような広い議題は禁止する。

## 完了時

セッションまとめと`030-outcome-routing-policy.md`による成果物判定を出す。通常はMVP計画更新とstate更新が必要になる。

ロードマップセット外の大きな技術判断が必要なら、現在議題をBlockerとして閉じ、判断議題を次の作業候補へ送る。ユーザーにADRを作るか選ばせない。
