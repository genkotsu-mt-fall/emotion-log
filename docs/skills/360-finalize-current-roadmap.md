# 360: 現在のロードマップを完了する

## 使用条件

- ロードマップ内の全必須タスクがDone
- 成果物が存在する
- 未適用変更や未解決Blockerがない

## 確認

- ロードマップ固有の完了条件
- 正本文書、ADR、OQ、変更記録の整合性
- 後続ロードマップの開始条件
- 隠れた運用、テスト、移行、監視作業
- ユーザーの完了承認

## 分岐

- 次ロードマップあり: そのスタブを`active_work.stage: open`へ
- MVP対象がすべて完了: `400-review-release-readiness.md`へ
- 不足あり: 新しいタスクまたは議題へ戻す

ロードマップをDoneにする更新は統合instructionで適用する。
