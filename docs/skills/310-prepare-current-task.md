# 310: 現在のタスクを実装可能にする

## 目的

Draftタスクを開き、実装を妨げる最小議題を一つずつ`210`で議論できる状態にする。議題がなければReady判定を行う。

## 確認項目

- 目的と利用者価値
- 対象と対象外
- 変更対象候補
- 入出力、エラー、境界条件
- データ、認証、セキュリティ
- UX、アクセシビリティ
- テスト、CI、手動確認
- 文書更新
- 完了条件
- 実装AIが判断してよい範囲

## 分岐

- 未決定議題あり: `active_work.stage: discuss`として`210`へ
- 外部判断がBlocker: 元タスクをreturn stackへ積み、判断議題へ
- すべて明確: タスクを`Ready`へする文書反映instructionを作る

Readyは、実装方針が一意であり、完了条件を検証できる状態を意味する。
