# 調査計画

- 版: 0.1.0
- 状態: Draft
- 作成日: 2026-07-25

## 1. 目的

プロダクトの解像度を上げ、現在の仮説を事実として誤認しないために、関連研究、既存サービス、利用者の実態を調査する。

調査はプロダクトの効果を過剰に主張するためではなく、扱う課題、用語、リスク、検証方法を正確にするために行う。

## 2. 調査テーマ

### 2.1 感情の言語化と外部化

- 感情ラベリング
- 表現的筆記
- ジャーナリング
- 感情を言語化する行為と自己認識
- 強い感情の最中と、時間を置いた振り返りの違い

### 2.2 自己追跡と振り返り

- ライフログ
- Quantified Self
- 日記や気分記録による自己理解
- 過去の記録を比較する行為
- 記憶の再構成と振り返りの限界

### 2.3 仮説生成と認知上の誤り

- 相関と因果の混同
- 錯誤相関
- 確証バイアス
- パターン認識
- 自己追跡データからの仮説生成

### 2.4 文章を書く習慣

- 日記や長文を書く頻度の変化
- SNSや短文コミュニケーションと文章作成
- 思考の言語化と記録習慣
- 「文章が書けなくなっている」という仮説の妥当性

### 2.5 センシティブ情報の共有

- 投稿単位の公開範囲
- 特定ユーザー・グループへの共有
- 公開期間の指定
- 公開範囲変更後のアクセス制御
- 一度閲覧された情報の不可逆性
- 閲覧者一覧、無断転載抑止、透かしの利点と副作用

### 2.6 既存サービス比較

比較対象には、次の種類を含める。

- 日記アプリ
- 気分記録アプリ
- ライフログアプリ
- SNS
- 限定共有サービス
- メンタルヘルス関連アプリ

比較項目:

- 入力項目
- 文章量
- 気分表現
- 振り返り表示
- 公開範囲
- 投稿単位の権限
- 公開範囲の変更
- データの書き出し
- 医療的な表現の有無

## 3. 利用者調査

### 3.1 初期ヒアリング

確認する内容:

- 普段、感情や考えを記録しているか
- どこへ記録しているか
- 後から読み返しているか
- 読み返す際に困ること
- 言葉にできないとき、何なら入力できるか
- 他者へ共有したい記録があるか
- 誰に見せたいか
- 一度共有した後に相手を変更したい場面があるか

### 3.2 プロトタイプ検証

比較候補:

- 時系列リスト
- カレンダー表示
- 時系列折れ線表示
- 時系列散布表示
- 複合表示

依頼する課題:

- 特定の日付のログを探す
- 気分値が大きく変化した時点を探す
- 選択したログの本文を読む
- 過去の一定期間へ移動する
- 新しい感情ログを登録する

## 4. 成果物

- 調査メモ
- 参考文献一覧
- 既存サービス比較表
- ヒアリング記録
- プロトタイプ検証結果
- Product Briefおよび要件への反映記録

## 5. 調査結果の扱い

- 根拠の強さを区別する
- 一つの研究だけで効能を断定しない
- 医療的な主張には特に慎重になる
- 利用者の感想と一般化可能な事実を分ける
- プロダクトに都合のよい情報だけを選ばない
