# RM1-T011: マウスとタッチのパン操作を作る

- 状態: Pending
- ロードマップ: [docs/roadmap/rm-001-time-axis-pagination-spike.md](../../roadmap/rm-001-time-axis-pagination-spike.md)
- 依存タスク: RM1-T010

## 目的

散布図上でマウスとタッチによる横方向パン操作を実現する。

## 対象

- マウスによる横方向パン操作
- タッチによる横方向パン操作
- OQ-028〜OQ-030の仮値の適用
- パン中とパン終了後の表示範囲取得

## 対象外

- キーボードによる時間移動（RM 6で実装）
- 縦方向のズーム
- 慣性パン

## 実装・調査内容

- マウスドラッグによる横方向パンの実装
- タッチスワイプによる横方向パンの実装
- パン開始閾値の適用（マウス：5 CSS px、タッチ：10 CSS px）
- パン判定の縦移動比率の適用（横移動が縦移動の1.2倍以上）
- パン中の表示範囲取得
- パン終了後の表示範囲取得

確認事項：

- 縦スクロールを不必要に妨げない

## エラーと境界条件

- 縦スクロールとの干渉
- 斜め方向の操作
- 高速フリック

## テストと確認

- マウスで横方向にパンできる
- タッチで横方向にパンできる
- 縦スクロールを不必要に妨げない
- パン中とパン終了後の表示範囲を取得できる

## 成果物

- マウスパン操作の実装
- タッチパン操作の実装

## 完了条件
