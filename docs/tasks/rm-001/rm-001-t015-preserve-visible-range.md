# RM1-T015: 追加取得後の表示位置を維持する

- 状態: Pending
- ロードマップ: [docs/roadmap/rm-001-time-axis-pagination-spike.md](../../roadmap/rm-001-time-axis-pagination-spike.md)
- 依存タスク: RM1-T014

## 目的

過去データの追加取得後に、利用者が見ていた表示位置を維持する。

## 対象

- 追加前の表示時間範囲の保存
- データ統合後の表示範囲の復元
- 追加前後の範囲比較
- 複数回追加した場合のずれ確認

## 対象外

- 表示位置維持方式の正式決定
- 未来方向への追加取得

## 参照文書

- [docs/roadmap/rm-001-time-axis-pagination-spike.md](../../roadmap/rm-001-time-axis-pagination-spike.md)
- [docs/decisions/open-questions.md](../../decisions/open-questions.md)（OQ-058）

## 変更対象

- 試作品のソースコード

## 実装・調査内容

- 追加取得前の表示時間範囲を保存する
- データ統合を行う
- 必要な表示範囲を復元する
- 追加前後の範囲を比較する
- 複数回追加した場合のずれを確認する

## エラーと境界条件

- 追加取得中にパン操作が行われた場合
- 複数回の追加取得でずれが積み重なる場合

## テストと確認

- 見ていた日時が画面外へ移動しない
- 3回以上追加してもずれが積み重ならない
- 追加前後で表示時間範囲が変わらない

## 成果物

- 表示時間範囲の保存と復元
- 追加前後の範囲比較
- 複数回追加のずれ確認結果

## 完了条件

- 見ていた日時が画面外へ移動しない
- 3回以上追加してもずれが積み重ならない

## 未決定議題

- OQ-058：表示位置維持方式（仮の方式で検証、正式決定はRM 2）
