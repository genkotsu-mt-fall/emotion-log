# 210: 現在の最小議題を議論する

## 目的

作業項目の種類に関係なく、同じ会話手順で一つの最小議題だけを深掘りする。

## 必ず参照

- `docs/skills/020-single-agenda-session.md`
- `docs/skills/030-outcome-routing-policy.md`
- `docs/state.md`
- `active_work`が指す文書
- 議題に直接関係する正本文書、ADR、OQ、ロードマップ、タスク

## 手順

1. 現在の議題を疑問文で再掲する
2. 確認済み事実と前提を分ける
3. 選択肢がある場合は比較軸を揃える
4. 一度に一問だけ聞く
5. 新しい独立議題は保留一覧へ送る
6. ユーザーの明示的な結論または保留判断を待つ

## 分岐

議論中に大きなアーキテクチャ判断などが必要になっても、その場で別議題を開始しない。

- 現在議題を`Blocked`候補にする
- 新しい判断を一つの最小議題として記録する
- セッションを閉じた後、ChatGPTがstateとOQへの反映を判断する
- 次回の「次に何すればいい？」で新しい判断を自動的に開く

## 終了

終了条件を満たしたら`220-close-session-and-route-outcome.md`へ進む。議論途中で成果物全文やinstructionを生成しない。
