# MVP機能要件

- 版: 0.2.0
- 状態: Draft
- 作成日: 2026-07-25
- 更新日: 2026-07-31

## 1. MVPの目的

自分の感情や考えを低い負担で記録し、時間の流れに沿って振り返る個人利用の体験が成立するかを検証する。

他者共有、フォロー、公開範囲の詳細設計はMVPの対象外とする。

## 2. アカウント

### 2.1 ユーザー登録

- 利用者はアカウントを作成できる
- 登録に必要な情報は別途定義する
- 他者のアカウントと重複しない識別子を持つ
- 本番URLへアクセスできる利用者は、管理者の招待や承認なしでアカウントを登録できる
- MVPでは招待コードを必須にしない
- アカウント登録後、管理者の手動承認を待たずに利用を開始できる
- 検索エンジンから発見できることはMVPの要件に含めない

### 2.2 ログイン・ログアウト

- 登録済み利用者はログインできる
- ログイン中の利用者はログアウトできる
- 未認証利用者は感情ログへアクセスできない

## 3. 感情ログ

### 3.1 作成

- 利用者は感情ログを作成できる
- ログ成立に必要な最小項目は、気分値と絵文字である
- 本文は任意である
- 感情日時は利用者が変更できる
- 感情日時が明示されない場合は、作成日時と同じ日時を使用する
- 保存後、現在の振り返り表示へ反映される

### 3.2 閲覧

- 利用者は自分の感情ログだけを閲覧できる
- ログ一覧または時系列表示から詳細を確認できる
- 本文が空の場合も、気分値、絵文字、感情日時を確認できる

### 3.3 編集

- 利用者は自分のログを編集できる
- 本文を後から追加できる
- 気分値、絵文字、本文、感情日時を変更できる
- 感情日時を変更した場合、時系列上の位置も更新される

### 3.4 削除

- 利用者は自分のログを削除できる
- 削除前に誤操作を防ぐ確認を行う
- 削除後は振り返り表示と一覧から取り除く

## 4. 入力

### 4.1 気分値

- 0から100までの整数を入力できる
- 0に近いほど本人にとってマイナス、100に近いほど本人にとってプラスを表す
- 50は中間の目安とする
- 数値の厳密な意味は利用者へ固定しない
- スライダー、数値入力、目盛り上の位置選択を同じ値へ同期させる
- キーボードから微調整できる

### 4.2 絵文字

- 利用者は自由入力した絵文字を1字登録できる
- あらかじめ用意した感情分類だけに制限しない
- 見た目上1字の絵文字を1つとして扱う
- 最近使用した絵文字などの入力補助は将来検討とする

### 4.3 本文

- 本文は任意とする
- 最大1000文字とする
- 1000文字はMVPの暫定値であり、利用状況をもとに見直す
- 記録後に追加、変更、削除できる
- 短い断片から複数段落まで入力できる
- 本文が空でも保存できる

### 4.4 感情日時

- 感情を感じていた日時を入力できる
- 入力画面では現在日時を初期表示する
- 過去日時へ変更できる
- 未指定の場合は作成日時と同じ日時を保存する
- 未来日時を許可するかは別途決定する

## 5. 振り返り

- 利用者は感情ログを時間の流れに沿って確認できる
- 気分値の変化または違いを視覚的に把握できる
- 気になるログを選択して詳細を確認できる
- 散布図上で重なったログを選び分けられる
- ページ番号を意識せず時間範囲を移動できる
- 表示範囲外のログを必要に応じて追加取得できる
- PC、タッチ端末、キーボードで操作できる

## 6. 画面構成

- 感情の記録、振り返り、詳細確認は、不要な画面遷移を伴わず主画面上で連続して操作できる
- ログインやアカウント設定は別画面としてよい
- 一つの巨大なUIコンポーネントへすべてを詰め込まない
- PC、iPhone、Androidのブラウザ幅へ対応する

## 7. MVPの対象外

- フォロー、フォロワー
- 他者への共有
- Web公開またはサービス内公開
- 閲覧可能者表示
- 透かし
- 公開期間
- コメント、いいね、メッセージ
- 通知
- 支援を求める意思の表示
- 仮説記録専用機能
- AIによる分析
- 感情分類
- 他者との気分値比較
- オフライン作成・同期
- PWA固有機能
- ネイティブアプリ配布

## 8. 品質上の要求

- 他の利用者のログを閲覧・更新・削除できない
- 入力値の検証はクライアント表示だけに依存しない
- 操作中に取得したログを重複表示しない
- データ取得失敗時も、既に表示したログを失わない
- スマートフォンで縦スクロールと時間軸の横パンを両立する
- キーボードだけでも主要操作を実行できる
