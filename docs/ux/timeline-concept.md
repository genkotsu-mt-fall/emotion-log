# 振り返り表示コンセプト

- 版: 0.1.0
- 状態: Prototype candidate
- 作成日: 2026-07-25

## 1. 目的

日記やつぶやきなどの断片的なログを、時間の流れに沿って振り返り、異なる時点を見比べられるようにする。

グラフを先に目的とせず、要求を満たす表示方法を比較する。

## 2. 表示に求めること

- ログの時間順序を把握できる
- 気分値がプラス側またはマイナス側へ動いた時点を見つけられる
- 長期間の中から気になる時期を探索できる
- ログ本文と絵文字を確認できる
- 記録がない期間を、気分が一定だった期間と誤解しにくい
- 複数のログを見比べられる
- ページ番号を意識せず時間を移動できる
- マウス、タッチ、キーボードで利用できる

## 3. 表示候補

### 3.1 時系列リスト

長所:

- 本文を読みやすい
- 操作が分かりやすい
- キーボードやスクリーンリーダーへ対応しやすい

短所:

- 気分値の変化を俯瞰しにくい
- 長期間の違いを見つけるために多くの文章を読む必要がある

### 3.2 カレンダー表示

長所:

- 特定の日付へ移動しやすい
- 記録のある日を把握しやすい

短所:

- 一日に複数回変化する感情を表現しにくい
- 時刻単位の連続的な探索に向かない

### 3.3 時系列折れ線表示

長所:

- 上下の方向と変化量を把握しやすい
- パンや表示範囲切り替えと相性がよい

短所:

- 記録の間も感情が連続していたように見える
- 記録していない期間を補間していると誤解される可能性がある

### 3.4 時系列散布表示

長所:

- 各ログが独立した記録であることを表せる
- 記録のない期間を補間しない
- 時間と気分値の関係を俯瞰できる
- 絵文字をデータ点として表示できる
- パン操作と相性がよい

短所:

- 点が重なる可能性がある
- 本文を読むには詳細表示またはリストが必要
- 同一時刻の複数ログに表示上の工夫が必要

## 4. 現時点の第一候補

一つの方式だけですべてを実現せず、次の複合構成を第一候補とする。

- 時系列散布表示を中心にする
- 横軸を時間とする
- 縦軸を0〜100の気分値とする
- 各ログを独立した点として扱う
- 点の表示には絵文字を使用する
- 選択したログの詳細を同じ主画面内に表示する
- 選択範囲のログを時系列リストでも読めるようにする
- 日付指定による移動を用意する
- 横方向のパンで時間を移動する

折れ線は初期状態で表示しない。変化方向を読みやすくする補助線として利用価値が確認された場合に検討する。

## 5. 画面構成

主画面の候補:

- 感情ログ入力領域
- 時間範囲の操作領域
- 時系列散布表示
- 選択ログの詳細領域
- 選択期間の時系列リスト
- 編集・削除操作

感情の記録、振り返り、詳細確認は、不要な画面遷移を伴わず、同一の主画面上で連続して操作できることを目指す。

## 6. 本文入力欄

初期候補:

- 初期表示は3〜4行
- 入力に応じて自動拡張する
- 8〜12行程度を超えた場合は内部スクロールまたは拡大表示を使う
- 長文入力用に拡大できる
- 最大1000文字であっても、初期状態で大きな入力欄を表示しない
- 文字数カウンターは上限へ近づいた場合に目立たせる

この数値は画面プロトタイプで調整する。

## 7. 検証項目

- 特定日時のログを見つけられるか
- 気分値が大きく異なる時点を見つけられるか
- ログ詳細を確認できるか
- 時系列散布表示とリストを行き来できるか
- 長期間を無理なく移動できるか
- 記録がない期間を誤解しないか
- 複数のログを比較しやすいか
- 表示を見た結果、気付きが自然に生じるか

パン操作へ説明なしで気付けるかは中心評価としない。必要に応じて初回ガイド、操作ヒント、カーソル、移動ボタンを追加する。
