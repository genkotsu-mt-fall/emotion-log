# RM1-T011: マウスとタッチのパン操作を作る

- 状態: Pending
- ロードマップ: [docs/roadmap/rm-001-time-axis-pagination-spike.md](../../roadmap/rm-001-time-axis-pagination-spike.md)
- 依存タスク: RM1-T010

## 目的

散布図上でPlotly.jsの標準パンを使い、マウスとタッチによる横方向の時間軸移動を実現する。

## 対象

- Plotly.jsの標準パンによるマウス操作
- Plotly.jsの標準パンによるタッチ操作
- パン中とパン終了後の表示範囲取得
- 縦スクロールとの干渉確認

## 対象外

- アプリ独自のパン開始閾値の実装
- アプリ独自の縦横移動比率によるパン判定
- キーボードによる時間移動（RM 1では評価対象外）
- 縦方向のズーム
- 独自の慣性パン実装

## 変更対象

- `prototypes/rm-001-scatter-pagination/`配下の試作品ソースコード

## 実装・調査内容

- Plotly.jsの標準パンを有効にする
- マウスドラッグで横方向に時間軸を移動できることを確認する
- タッチ操作で横方向に時間軸を移動できることを確認する
- Plotly.jsが提供するイベントと軸範囲から、パン中の表示範囲を取得する
- Plotly.jsが提供するイベントと軸範囲から、パン終了後の表示範囲を取得する

RM 1では、次の候補値をアプリ独自の判定として実装しない。

- マウス: 5 CSS px
- タッチ: 10 CSS px
- 横移動が縦移動の1.2倍以上

確認事項：

- 縦スクロールを不必要に妨げない
- PCとモバイルでPlotly.js標準パンの挙動に差がある場合は記録する

## エラーと境界条件

- 縦スクロールとの干渉
- 斜め方向の操作
- 高速なタッチ操作
- PCとモバイルで標準パンの挙動が異なる場合

## テストと確認

- マウスで横方向にパンできる
- タッチで横方向にパンできる
- 縦スクロールを不必要に妨げない
- パン中とパン終了後の表示範囲を取得できる
- アプリ独自のパン開始閾値や縦横移動比率を実装していない

## 成果物

- Plotly.js標準パンを使ったマウス操作
- Plotly.js標準パンを使ったタッチ操作
- パン中とパン終了後の表示範囲取得
- 標準パンと縦スクロールの干渉確認結果

## 完了条件

- マウスとタッチで横方向にパンできる
- 縦スクロールを不必要に妨げない
- パン中とパン終了後の表示範囲を取得できる
