# 200: 現在の作業項目を開く

## 目的

`active_work`または`return_stack`から、現在扱う文書と作業段階を確認し、次の最小議題一件を選ぶ。

## 対象

- MVP計画
- 個別ロードマップ
- タスク
- 技術・プロダクト判断
- OQ
- リリース準備
- リリース後検証

成果物種別ごとの専用入口をユーザーへ要求しない。

## 手順

1. stateの対象と実ファイルを照合する
2. 上位文書、依存関係、Blockerを読む
3. 既に決定済みの事項を除外する
4. 曖昧さを最小議題へ分割する
5. 最も先行依存性が高い一件を選ぶ
6. `active_work.stage: discuss`として扱うstate更新仕様を作る

## 出力

- 作業対象
- 現在の状態
- 今回の最小議題
- 選定理由
- 今回扱わない議題
- 次の`210-discuss-current-agenda.md`で最初に聞く質問

このスキルでは議題の結論を出さない。
