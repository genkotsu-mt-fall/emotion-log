# RM1-T016: 複数回取得と対象端末で検証する

- 状態: Pending
- ロードマップ: [docs/roadmap/rm-001-time-axis-pagination-spike.md](../../roadmap/rm-001-time-axis-pagination-spike.md)
- 依存タスク: RM1-T015

## 目的

複数回の追加取得と対象端末での動作を検証し、結果を記録する。

## 対象

確認環境：

- PCブラウザ
- 可能であればトラックパッド
- iPhone Safari
- Android Chrome

確認操作：

- 初期表示
- 過去方向へのパン
- 境界での追加取得
- 3回以上の追加取得
- 表示位置維持
- 重複と欠落
- 最古到達後の停止
- 素早い往復操作
- 縦スクロールとの干渉

## 対象外

- 不具合の修正（修正が必要な場合は前のタスクへ戻る）
- 正式な性能テスト

## 実装・調査内容

- 各確認環境で確認操作を実行する
- 端末、OS、ブラウザ、入力方法を記録する
- 成功、失敗、未確認事項を記録する

## エラーと境界条件

- 特定の端末で動作しない場合
- 素早い往復操作での不具合
- 縦スクロールとの干渉

## テストと確認

- PC、iPhone、Androidでの確認が完了している
- 成功、失敗、未確認事項が記録されている

## 成果物

- 端末ごとの検証結果
- 成功した操作の一覧
- 失敗した操作の一覧
- 未確認事項の一覧

## 完了条件

- PC、iPhone Safari、Android Chromeで必須の確認操作が成功している
- 3回以上の追加取得が成功している
- 表示位置維持、重複防止、欠落防止、最古到達後の停止が成功している
- 必須端末で失敗した場合は、原因に対応する前工程のタスクへ戻り、修正後に再検証している
- 失敗が残っている場合はT016をCompletedにしない
- 未確認を許容するのは「可能であれば」としたトラックパッドなど、明示的な任意項目だけとする
- 必須操作が失敗した場合の状態は、BlockedまたはIn progressとして扱う
