# ADR作成ハンドラー

## 作成条件

- 一つの継続的な技術判断
- ユーザー承認済み
- 比較理由と再検討条件を保存する価値がある

## 規則

- `docs/architecture/adr/NNNN-short-title.md`
- 既存最大番号+1。`TEMPLATE.md`は採番対象外
- 一ADR一判断
- 採用済み判断の変更は新ADRでSupersedeする
- 状態、日付、背景、判断基準、選択肢、結論、理由、結果、確認方法、再検討条件、関連文書を記載する
- OQを解決する場合は相互参照する
- 正本文書やロードマップへの必要反映を同じinstructionへ含める
