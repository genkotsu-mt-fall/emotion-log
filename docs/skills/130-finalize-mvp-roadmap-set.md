# 130: MVPロードマップセットを確定し、スタブを作る

## 使用条件

- `docs/roadmap/000-mvp-release-plan.md`が`Ready`
- 大項目の境界、順序、依存関係、MVPリリース到達点にBlockerがない
- ユーザーがロードマップセットを承認している

## 目的

MVP計画の各大項目から、個別ロードマップのDraftスタブを一括生成する。詳細タスクはまだ作らない。

## 成果物

- `docs/roadmap/001-<name>.md`以降
- 各スタブのID、目的、期待成果、前提、対象外、完了境界、状態
- `000-mvp-release-plan.md`から各スタブへのリンク
- 最初に開くロードマップ
- `docs/state.md`更新
- 統合instruction

## 規則

- 番号はMVP計画の実行順を基本とする
- 循環依存を作らない
- 未決定技術をスタブで勝手に採用しない
- すべてを直列にしない。並行可能なものは明記する
- 最後に本番リリースと本番確認へ到達できることを確認する

適用・レビュー後、`active_work`は最初のロードマップの`open`となる。
